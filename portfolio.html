09 / STREAMING SOFTWARE
WINDOWS // LOCAL SOFTWARE // WORKING PROTOTYPE

StreamBridge

I was tired of paying subscriptions just to send my livestream to multiple platforms, so I made my own. StreamBridge takes one stream from OBS and forwards it to multiple RTMP destinations from my PC, with support for manually configured YouTube, Twitch, X, and custom server URLs.

The app includes a local control panel, individual destination controls, encrypted saved stream keys, and automatic reconnection for each output. It uses my own upload bandwidth, with no cloud relay subscription.

Node.jsFFmpegRTMP / RTMPSOBSWindows

Validated with real audio and video sent to two simultaneous local RTMP receivers. Live platform broadcasts still need account-specific testing.

Built to solve my own streaming needsLOCAL PROTOTYPE
