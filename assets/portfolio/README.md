# Portfolio media slots

Drop exported images into this folder using these exact filenames. The portfolio will display them automatically; until then, each project shows a branded placeholder.

| Project | Suggested file | Best content |
| --- | --- | --- |
| Unity 4-Player RPG Framework | `unity-rpg-framework-cover.jpg` | Gameplay screenshot, party UI, or a systems diagram |
| Bazoo AI Studio | `bazoo-ai-studio-cover.jpg` | Tool interface, local workflow, or model dashboard |
| AI NPC TikTok Interaction System | `ai-npc-tiktok-cover.jpg` | Character demo, interaction flow, or TikTok capture |
| Dear Passengers Parody | `dear-passengers-cover.jpg` | Roblox gameplay screenshot or key art |
| OpenGOAL Jak Multiplayer Research | `opengoal-jak-cover.jpg` | Architecture sketch, research graphic, or prototype capture |
| Raspberry Pi Networking Projects | `raspberry-pi-networking-cover.jpg` | Hardware / cable / device photograph |
| UEFN & Fortnite Verse Projects | `uefn-verse-cover.jpg` | UEFN editor or in-game screenshot |
| About page portrait | `dakota-f-portrait.jpg` | Professional headshot or studio photograph |

Recommended exports: landscape JPG or WebP, at least 1600 × 900 pixels, under 1 MB when possible. Never upload client work, personal documents, private source code, API keys, or unreleased material you do not have permission to share.
